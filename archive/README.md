# Archivo histórico

Notas de planificación, puesta en marcha y análisis de los archivos de entrada, escritas **antes** de que el proyecto estuviera implementado. Se conservan por su valor histórico y **pueden estar desactualizadas o ser incorrectas** (por ejemplo: mencionan `App.java`, `application.properties`, `manifest.txt`, clases que se retiraron, JUnit, o un formato de catálogo con hojas distintas al real).

Para la información vigente usa:

- [`../README.md`](../README.md): uso, compilación y estructura.
- [`../LOGICA_DEL_PROGRAMA.md`](../LOGICA_DEL_PROGRAMA.md): cómo funciona el programa.
- [`../CLAUDE.md`](../CLAUDE.md): comandos verificados y convenciones.

Contenido: `START_HERE`, `INDEX`, `QUICK_START`, `REFERENCE`, `SETUP_COMPLETE`, `ANT_SETUP`, `GENERATED_ARTIFACTS`, `PROGRESS`, `PROJECT_STRUCTURE`, `IMPLEMENTATION_GUIDE`, `EXCEL_FORMAT_GUIDE`, `XLSX_ANALYSIS_REPORT`, `XLSX_STRUCTURE_ANALYSIS`.

`XLSX_STRUCTURE_ANALYSIS.md` y `XLSX_ANALYSIS_REPORT.md` documentan cómo se descubrió el formato real de los archivos de entrada; el formato vigente está descrito en `LOGICA_DEL_PROGRAMA.md` (§3, §4.1 y §4.2).
